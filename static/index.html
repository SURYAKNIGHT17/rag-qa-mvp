📖 RAG System User Manual

1. System Overview

This RAG (Retrieval-Augmented Generation) system extracts text from PDF and TXT documents, chunks the content into overlapping segments, converts text into 384-dimensional dense vectors using SentenceTransformers, and indexes vectors into FAISS. When you ask a question, the system searches the index using exact Cosine Similarity and grounds answers strictly in retrieved content.

2. How to Use

  1. Upload Documents: Drag & drop your PDF or TXT file into the Document Ingestion zone on the left sidebar.
  2. Ask Questions: Type any question in the main search bar or click one of the suggested query pills.
  3. View Grounded Answer & Sources: Review the generated answer and expand the Source Attribution cards to see exact document page numbers, similarity scores, and text snippets.
  4. Hallucination Guardrail: If a question cannot be answered from your documents, the system returns "The answer could not be found in the provided documents." rather than inventing false claims.

3. API Reference

  • GET /health: System status and indexed document count.
  • POST /documents/upload: Ingest PDF or TXT files.
  • POST /query: Search indexed chunks and generate grounded answers.
