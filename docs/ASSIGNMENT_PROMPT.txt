# ASSESSMENT

I am completing an AI Engineer / Applied AI — Forward Deployed Track assessment.

The task is:

## RAG Question Answering

A user uploads reference documents and asks questions about them.

The system retrieves relevant material from those documents and generates an answer grounded in the retrieved material.

The system must NOT invent answers when the information isn't present.

---

# REQUIRED FUNCTIONALITY

The final application MUST:

1. Accept PDF files.
2. Accept TXT files.
3. Extract text.
4. Chunk the text.
5. Generate embeddings.
6. Store embeddings in a local vector store.
7. Accept user questions.
8. Embed the question.
9. Retrieve relevant chunks.
10. Generate an answer using retrieved context.
11. Return the source chunks.
12. Handle questions whose answers are not present in the documents.
13. Handle LLM/embedding failures gracefully.
