# scripts/

One-off utility scripts used during development. Not required to run the application.

| Script | Description |
|--------|-------------|
| `generate_explanation_pdf.py` | Generates `docs/submission/EXPLANATION.pdf` from Markdown source |
| `generate_user_manual.py` | Generates `docs/RAG_System_User_Manual.pdf` user guide |

## Usage

```bash
# Regenerate the explanation PDF
python scripts/generate_explanation_pdf.py

# Regenerate the user manual PDF
python scripts/generate_user_manual.py
```
